A browser for playing FISHAO and the Flash games that came with it.

Flash was retired in 2020, but the games still work — if you have a browser that still runs it. FISHAO Browser is exactly that: Flash Player is included and loads automatically, nothing to install or configure.

What this is

Take your own with Win+Shift+S while the browser is open, save it as screenshot.png next to this file, and push — the page picks it up automatically.

Purpose
One job: run FISHAO and other Flash Player content on modern Windows, years after Flash's end of life.
Engine
Electron 9 / Chromium 83 — the last line with PPAPI plugin support. Chosen deliberately; it cannot be upgraded without losing Flash.
Flash Player
Included in the download (pepflashplayer64.dll) and loaded automatically at startup. No setup.
Privacy
No telemetry, no analytics, no update pings. Bookmarks, history and preferences stay in a local file on your machine.
Features
Tabs, bookmarks with folders and drag & drop, history with search, per-tab mute, zoom, session restore, 8 themes plus custom CSS themes.
License
MIT. Source on GitHub. Not affiliated with FISHAO or Adobe.

Installing

  1. Download and run the installer

    Your browser may call the file "uncommon" — normal for unsigned community software; choose Keep. SmartScreen may ask once: More info → Run anyway.

  2. Accept the license, pick a folder

    The wizard shows the EULA, then the destination — the default C:\Program Files\FISHAO Browser is fine. That's it; Flash is already inside.

  3. Play

    The browser opens on fishao.com. Bookmark it with Ctrl+D, pick a theme in Settings if you like. Having trouble? The Discord answers fast.
