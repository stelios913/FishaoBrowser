Why a whole browser for one game?

Because keeping Flash alive safely means keeping it contained: an engine pinned to the last version that ever ran Flash, with nothing else bolted on.

Built for Flash

Ships the last Chromium line with PPAPI plugin support and expects you to supply your own Flash Player binary — exactly how preservation should work.

Zero telemetry

No analytics, no update pings, no phoning home. Preferences, bookmarks and history stay in a local file on your PC.

Real bookmarking

Folders with drag & drop, an all-bookmarks popup, editing dialog with folder assignment — plus 8 themes and custom CSS themes.

Installer that behaves

A proper wizard: EULA first, choose your install folder, installs into Program Files, and a clean uninstaller when you're done.

Session restore

Reopen the tabs from your last session, per-site mute memory, Ctrl + mouse-wheel zoom — small browser comforts, kept.

Honest about limits

The engine is end-of-life on purpose. The EULA says plainly: play games with it, don't bank with it. Isolation is your call (VM recommended).

Install guide

Three minutes, start to finish.

Download the installer

Click Download setup.exe. Your browser may warn that the file is uncommon — that's expected for unsigned community software; choose Keep.

Read the license, pick a folder

The wizard shows the EULA first (please actually read section 2 — it explains the end-of-life stack), then lets you choose the install location. The default C:\Program Files\FISHAO Browser is fine for most people.

Point it at a Flash Player plugin

The browser does not ship Flash itself. Put your pepflashplayer64.dll where you can keep it and check src/plugins/flash/README inside the install folder for what to do — or ask in Discord, we'll help.

Play

Open the browser, it lands on your homepage, FISHAO loads. Bookmark it (Ctrl+D), pick a theme in Settings, done.

SmartScreen note. The installer is unsigned, so Windows Defender SmartScreen may show "Windows protected your PC" on first run. Click More info → Run anyway. Only download from this page or the project's GitHub Releases — nowhere else.
